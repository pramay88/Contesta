# ContestX

> **Track competitive programming contests from multiple platforms in one place.**

ContestStack aggregates upcoming programming contests from major competitive programming platforms into a single, clean interface—so you spend less time checking platforms and more time competing.


### Platforms

`LeetCode` · `Codeforces` · `CodeChef` · `AtCoder` · `GeeksforGeeks` · `Coding Ninjas` · `HackerEarth` · `HackerRank`

### Stack

`React` · `TypeScript` · `Tailwind CSS` · `Upstash Redis` · `REST APIs`

### Live

**[ContestX](https://contestx.vercel.app/contests)**

### Local

```bash
git clone https://github.com/pramay88/conteststack.git
cd conteststack
npm install
npm run dev
```

Configure the required Redis and contest API environment variables in `.env.local` before running the application.
